# Sales Performance Dashboard Using Microsoft Excel

## Project Overview
This project focuses on analysing sales data and creating an interactive Sales Performance Dashboard using Microsoft Excel.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Formulas

## Dashboard Features
- Total Revenue
- Total Orders
- Units Sold
- Average Order Value
- Sales by Product
- Sales by Region
- Sales by Payment Method
- Top Salesperson
- Recent Sales Performance

## Excel Skills Used
- Data Cleaning
- Sorting and Filtering
- PivotTables
- PivotCharts
- Dashboard Design
- Data Visualization

## Project Objective
To analyse sales performance, understand business trends and present useful information through an interactive Excel dashboard.
